# HTML 冲突报告样式说明

这个 skill 不把命名冲突确认内容写入 Figma 画板。需要人工判断时，只输出一份本地 HTML 冲突报告。

适用条件：

- 只在“视觉完全一致且 `display_name` 不同”时请求用户确认。
- `display_name` 相同但 `component_id` 或 `variant_id` 不同，属于机器字段问题，直接自动修正，不进入报告。
- 报告样式、字段、预览完整展示要求，以及 Figma 变体子组件的 `属性名=中文变体` 展示规则，统一以 `Naming_Component_Notes.md` 为准。

输出约束：

- 单次执行只生成一份 HTML 报告。
- 多个冲突组按纵向顺序追加到同一份报告里。
- 报告内可以展示 `属性名=中文变体｜component_id#variant_id` 这类完整短名称，但不要展示重复写法。
- 报告内不要写“请确认是否同一组件”这类引导语；引导语放在 Codex 回复正文里。
